Del problema a un modelo

La Investigación de Operaciones busca transformar problemas reales de asignación de recursos en modelos matemáticos que permitan analizar y encontrar soluciones. El procedimiento consiste en comprender la situación, identificar las decisiones, construir el modelo y posteriormente interpretar la solución.

Pasos para construir un modelo de programación lineal:

Definir las decisiones y sus unidades.

Asignar una variable de decisión a cada decisión.

Construir la función objetivo, que puede buscar maximizar un beneficio o minimizar un costo.

Establecer las restricciones que representan los recursos, requisitos o condiciones del problema.

Agregar las condiciones de no negatividad.

Revisar que las dimensiones, unidades y significado de cada expresión sean correctos.

Función objetivo

Z = c₁x₁ + c₂x₂ + ⋯ + cₙxₙ

Para maximización:

Max Z = c₁x₁ + c₂x₂ + ⋯ + cₙxₙ

Para minimización:

Min Z = c₁x₁ + c₂x₂ + ⋯ + cₙxₙ

Condición de no negatividad:

xᵢ ≥ 0

Un modelo es lineal cuando las variables aparecen solamente con potencia 1 y no se multiplican entre sí.

Matrices

Una matriz organiza información en filas y columnas. Si tiene m filas y n columnas, su dimensión es m × n.

A = (aᵢⱼ)ₘₓₙ

Para sumar o restar matrices deben tener las mismas dimensiones. Para multiplicarlas, el número de columnas de la primera debe coincidir con el número de filas de la segunda.

Aₘₓₙ Bₙₓₚ = Cₘₓₚ

La transpuesta se obtiene intercambiando filas por columnas:

Aᵀ = (aⱼᵢ)

Un sistema de ecuaciones puede escribirse en forma matricial como:

AX = B

Y su matriz aumentada como:

[ A | B ]

El método de Gauss utiliza operaciones elementales sobre las filas para transformar el sistema y facilitar su resolución.

Preparar el modelo para Simplex

Para aplicar el método Simplex, las restricciones deben llevarse a una forma adecuada. Dependiendo del signo se agregan variables de holgura, exceso o, cuando es necesario, variables artificiales.

Restricción menor o igual (≤)

aᵀx ≤ b  →  aᵀx + s = b,    s ≥ 0

La variable s es una variable de holgura y representa el recurso que no se utiliza.

Restricción mayor o igual (≥)

aᵀx ≥ b  →  aᵀx − e = b,    e ≥ 0

La variable e es una variable de exceso y representa cuánto se supera un mínimo requerido.

Variable artificial

a ≥ 0

Se utiliza para obtener una base inicial en determinadas restricciones y debe desaparecer de la solución final.

Cálculos de la tabla Simplex

Cálculo de Zⱼ:

Zⱼ = Σᵢ Cᴮᵢ aᵢⱼ

Costo reducido:

Cⱼ − Zⱼ

En maximización entra la variable con el mayor valor positivo y se termina cuando:

Cⱼ − Zⱼ ≤ 0

En minimización entra la variable con el valor más negativo y se termina cuando:

Cⱼ − Zⱼ ≥ 0

Prueba de la razón

θᵢ = bᵢ / aᵢₖ,    siempre que aᵢₖ > 0

Se elige la menor razón no negativa.

Ejemplo de Gran M

Min C = 6x₁ + 8x₂

x₁ + x₂ = 5000

x₁ ≤ 1500

x₂ ≥ 750

x₁, x₂ ≥ 0

Forma estándar:

x₁ + x₂ + a₁ = 5000

x₁ + s₁ = 1500

x₂ − e₂ + a₂ = 750

Función penalizada:

Min C = 6x₁ + 8x₂ + M a₁ + M a₂

Solución:

x₁ = 1500,    x₂ = 3500

Cₘᵢₙ = 37000

e₂ = 2750,    s₁ = 0

Ejemplo completo de maximización

Función objetivo:

Max Z = 4x₁ + 6x₂

Sujeto a:

0.5x₁ + x₂ ≤ 600

12.5x₁ + 10x₂ ≤ 10000

x₁ ≤ 700

x₁, x₂ ≥ 0

Forma estándar:

0.5x₁ + x₂ + s₁ = 600

12.5x₁ + 10x₂ + s₂ = 10000

x₁ + s₃ = 700

Solución:

x₁ = 1600/3 ≈ 533.33

x₂ = 1000/3 ≈ 333.33

Zₘₐₓ = 12400/3 ≈ 4133.33

Variables de holgura:

s₁ = 0,    s₂ = 0,    s₃ = 500/3 ≈ 166.67

Si el problema exige cantidades enteras, no se debe redondear automáticamente; se requiere un tratamiento de programación entera.

El Simplex como rutina

Escribir el modelo de programación lineal.

Transformar las restricciones a la forma necesaria.

Construir la tabla inicial y seleccionar la base inicial.

Identificar la variable que entra.

Calcular la prueba de la razón θ.

Identificar la variable que sale.

Seleccionar el elemento pivote.

Normalizar la fila pivote.

Hacer ceros en las demás posiciones de la columna pivote.

Recalcular la tabla.

Repetir hasta cumplir la condición de optimalidad.

Leer y verificar la solución en el problema original.

Situaciones especiales

Múltiples soluciones óptimas: existe más de una solución que proporciona el mismo valor óptimo.

Degeneración: puede presentarse cuando una variable básica toma el valor de cero.

Problema infactible: no existe una solución que satisfaga simultáneamente todas las restricciones.

Problema no acotado: la función objetivo puede mejorar indefinidamente sin que las restricciones establezcan un límite.

Conceptos y verificación

Variable básica: forma parte de la base actual.

Variable no básica: no pertenece a la base y normalmente toma valor cero en la solución básica.

Columna pivote: corresponde a la variable que entra.

Fila pivote: se determina mediante la prueba de la razón.

Precio sombra: cambio en el valor óptimo asociado con una unidad adicional de un recurso, dentro del rango válido.

Mezcla de solución: cantidades de las variables de decisión que forman la solución.

Para verificar una solución se debe:

Sustituir los valores en las restricciones originales.

Comprobar la no negatividad.

Revisar unidades y significado de las variables.

Recalcular la función objetivo.

Interpretar las variables de holgura y los recursos utilizados.

Determinar si la solución es óptima o presenta una situación especial.

Aplicación adicional

Para aumentar el inventario en 25 %:

Aₙᵤₑᵥₒ = 1.25A

Si los precios unitarios son:

P = [ 350   15   20 ]ᵀ

El costo puede expresarse mediante el producto matricial correspondiente:

C = AP

Cuando las cantidades de compra deben ser enteras, la decisión de redondeo debe establecerse explícitamente.

Conclusión

La Investigación de Operaciones permite transformar problemas de asignación de recursos en modelos matemáticos que facilitan la toma de decisiones. Primero se identifican las variables, la función objetivo y las restricciones; después se organiza el modelo y, cuando corresponde, se utiliza el método Simplex para obtener una solución óptima. Las matrices ayudan a representar y operar la información de manera ordenada, mientras que las variables de holgura, exceso y artificiales permiten preparar las restricciones para el procedimiento. Finalmente, una solución no debe limitarse a obtener números: es necesario comprobar que cumpla las restricciones originales, interpretar los recursos utilizados y explicar qué significa la solución dentro del problema planteado.
